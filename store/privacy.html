AI Organize Groups privacy policy

Effective date: October 11, 2026.

What is shared

When you request tab groups, the extension sends tab titles, URLs, and identifiers to the model provider over HTTPS. Titles and URLs may contain sensitive information. Page contents are not read or sent. The current version supports OpenAI; its data policies apply to information it receives. Requests disable response storage; other provider retention may still apply.

This information is used only to generate your requested groups. The developer does not receive your browsing data, sell it, use it for advertising, or include analytics.

What is stored

Your API key stays in extension-only session storage unless you choose Remember key, which saves it locally without encryption. It is sent only to the model provider for authentication and never synced through Chrome. Forget key deletes it. Model settings are stored locally; proposal history is not saved. Uninstalling removes stored settings.

Groups change only after approval. Rejecting a proposal does not undo information already sent to the provider.
