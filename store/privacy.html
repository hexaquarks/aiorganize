AI Organize Groups privacy policy

Draft for owner review. Before publication, add the developer's contact address and effective date and host this policy at the URL entered in the Chrome Web Store.

Data sent to OpenAI

When you click Organize tabs, the extension reads tab titles, full URLs, and internal identifiers for the current window. It reads up to 4,000 characters of visible text from each page with an ambiguous title, including signed-in pages when accessible. Titles, URLs, and page text may contain sensitive personal information; that information is not filtered out.

The extension sends this context directly to the OpenAI API to generate proposed groups, using the API key you enter in API settings. This data is processed for the grouping feature, not for sale, advertising, or credit decisions. Requests disable Responses API storage, but OpenAI's other data handling and retention depend on its policies and your account settings. See OpenAI's API data controls.

Your API key

The key is kept in extension-only session storage by default and is cleared when Chrome restarts or the extension reloads. If you select Remember key on this device, it is saved locally without encryption. It is never stored in Chrome Sync, included in extension releases, or sent to websites. It is sent only to OpenAI to authenticate your requests. Forget key removes it from both storage areas.

Storage and controls

The extension does not save proposal history or include analytics. Context and proposals are held in memory for a request. The selected model is stored locally. Chrome groups change only after you approve; rejecting a proposal prevents changes but does not undo data sent for generation.

Uninstalling the extension removes its stored settings. OpenAI-held data remains subject to its controls. The release runs in Chrome and requires no local companion or Python installation.
