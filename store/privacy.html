AI Organize Groups privacy policy

Draft for owner review. Before publication, add the developer's contact address and effective date and host this policy at the URL entered in the Chrome Web Store.

Data used to organize tabs

When you click Organize tabs, the extension reads tab titles, full URLs, and tab identifiers for the current window. It can read up to 4,000 characters of visible text from each inspected page, including signed-in pages. Titles, URLs, and page text can contain sensitive personal information. The extension does not filter that information out. Only request grouping for a window whose content you are willing to send to OpenAI.

Local companion and OpenAI

The extension sends tab context to a Python companion installed on your computer through Chrome native messaging. The companion sends titles, URLs, internal tab identifiers, and inspected page text to the OpenAI API to generate proposed groups. The model may request additional page text during that request. This data is processed for the grouping feature, not for sale, advertising, or credit decisions.

Your OpenAI API key is stored in your local environment or companion configuration. It is used to authenticate to OpenAI and is not bundled in or sent to the extension. OpenAI's handling and retention of API data depend on its policies and your account settings. See OpenAI's API data controls. This feature is not entirely offline.

Storage and controls

The application does not maintain a browsing database, save proposal history, or include analytics. Tab context and proposals are held in memory for a request. Your local configuration, Chrome's applied groups, and any separately enabled provider or environment logging have their own lifetimes. Rejecting a proposal prevents tab changes but does not undo data already sent for generation.

Chrome tab groups change only after you approve a proposal. Stop using or uninstall the extension to stop future requests. Uninstalling the extension does not remove the separately installed Python companion or your local API key configuration. Remove those separately if no longer needed. Provider-held data is subject to the provider's controls.
